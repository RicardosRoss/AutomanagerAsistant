# Telegram 自控力助手 - 命令列表

请在与机器人的私聊中使用命令和按钮。群聊只提示转到私聊，不修改个人任务、预约或修仙资产。命令支持 `/task@AutomanageMyselfBot 描述 45` 形式和大小写，发给其他机器人的命令会被忽略。

判例按钮只处理该条消息对应的决定。旧按钮过期后，用 `/reserve_status` 找回辅助链判例，用 `/violation` 找回已有主链判例；上报新的主链行为使用 `/violation 行为描述`。重复上报不会替换尚未处理的判例。

点击开始后若没有看到确认，可先用 `/status` 查看。有效启动不再等待按钮弹窗的网络响应；本人已兑现且仍在运行的预约再次点击会返回原任务，不重新计时。若预约确实过期，仍须用 `/reserve_status` 处理判例。

新任务描述最多1000个Unicode字符，草稿和直接命令使用同一上限；过长输入在建立承诺前提示修改。历史长描述在状态页显示预览，原内容保留；运行中的任务可从 `/status` 完成或标记未完成，正在启动的任务先显示查看状态按钮。判例列表会分段显示，并标明当前或历史链的作用域。

## Nautilus 日程提醒

`/schedule` 查看今天、`/schedule tomorrow` 查看明天、`/schedule YYYY-MM-DD` 查看指定日期的同步快照，按 `Asia/Shanghai` 展示提醒时间和投递状态。

通过 Nautilus skill 修改计划后自动同步到 VPS，手工改日记需再执行同步命令。提醒提供准备开始、15 分钟内启动和今天略过；确认前不建立专注或预约承诺，略过日程不影响链条。电脑关闭不影响已同步提醒。见 `integrations/nautilus-planner/README.md`。

计划结束时间只用于显示排程，不是任务的操作截止时间。超过计划时间后，原提醒和 `/schedule` 仍可准备开始、预约或略过，准备时沿用计划时长。错过自动提醒、投递失败或投递结果未知的项目仍显示为待处理，不集中补发通知。主动略过，或在 Obsidian 完成/删除后重新同步，才移除操作入口；进入准备后退出或准备失效，也可从日程再次准备。跨日的旧任务可以点击原提醒，或用 `/schedule YYYY-MM-DD` 找回。

## 基础命令

**start** - 开始使用修仙助手，查看欢迎信息和功能介绍
**help** - 显示帮助信息和所有可用命令

## 任务管理命令

**task** - 创建专注任务（格式：/task 任务描述 时长）
**reserve** - 建立预约承诺，并在15分钟内开始任务
**status** - 查看当前任务状态和链条信息
**stats** - 查看今日统计和历史总览

时长可写整数分钟数或明确单位：60、1h、1.5h、30m、45min、30分钟、2小时。生产环境换算后必须为5到480之间的整数分钟；不填时长使用个人默认设置。预约仍要求在15分钟内启动，任务时长单位不会改变预约期限。

只准备而不建立承诺：发送 /reserve 或 /task，回复内容，再在确认页选择时长。/status 可以继续已有准备；重复打开或切换准备模式会保留内容与时长。正式确认后，预约取消或延期需要按下必为例处理。

## 修仙系统命令

### 境界与修炼

**realm** - 查看当前境界、灵力和修炼状态
**mystats** - 查看个人修仙统计（渡劫、占卜、成就等）
**stones** - 查看仙石余额和盈亏统计

### 占卜天机

**divination** - 占卜天机（格式：/divination 仙石数量）
**divination_history** - 查看占卜历史记录（最近10次）
**divination_chart** - 查看占卜走势图和统计

### 境界突破

**breakthrough** - 尝试渡劫突破当前境界
**ascension** - 查看当前飞升条件并进入确认
**confirm_ascension** - 确认飞升操作

### 排行榜

**rankings** - 查看修仙排行榜（灵力榜、境界榜、飞升榜）

## 高级功能命令

**week** - 查看最近7天专注统计和报告
**settings** - 个人设置（默认时长、时区、提醒偏好等）
**patterns** - 查看和管理定式（下必为例原理）
**violation** - 报告主链行为并进行下必为例判定
**precedents** - 查看当前与历史任务链的判例
**reserve_status** - 查看已有预约、启动进展或辅助链待判例

## 命令使用示例

### 基础任务

```
/start
/task 学习编程 45
/reserve 准备考试 60
/reserve 填表 1h
/status
```

### 修仙系统

```
/realm
/divination 50
/divination_history
/breakthrough
/rankings
/mystats
```

### 完整工作流

```
1. /reserve → 准备一件事，回复内容并选择时长
2. [确认预约] → 建立在15分钟内开始的承诺
3. [开始专注] → 兑现预约并进入主任务
4. 按约定专注到结束，再点击[完成任务] → 保存主链节点与可信分钟
5. /status → 查看结果或准备下一项；/realm → 查看单独同步的附加奖励
```

## 快捷回调按钮

除了命令外，bot 还提供以下快捷按钮：

- **⏰ 准备预约** - 先收集内容，确认后才建立预约
- **🚀 已准备好，立即开始** - 进入立即开始的准备页
- **继续准备／退出准备** - 保留已有内容或退出未承诺的草稿
- **⚡ 查看境界** - 查看修仙状态
- **📊 修仙排行榜** - 查看排名
- **❓ 帮助** - 显示帮助信息
- **✅ 完成任务** - 标记任务完成
- **❌ 放弃任务** - 放弃当前任务

## 注意事项

1. **神圣座位原理**：主链任务失败会重置当前主链记录
2. **灵力获取**：按当前修仙奖励表结算，未达到门槛的短任务不承诺灵力奖励
3. **附加奖励**：按当前修仙规则单独同步；不影响已完成的主链确认或下一项启动，灵石没有固定的每分钟收益
4. **占卜风险**：改变灵石余额和后续奇遇效果，本次不直接改变境界或修为
5. **突破与飞升**：以 /breakthrough、/ascension 和 /realm 显示的当前条件为准，不承诺固定成功率
6. **失败与例外**：未能完成会断开当前主链；违规行为只能断链或成为当前链永久允许的判例
